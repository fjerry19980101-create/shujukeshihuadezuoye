# 嘉兴大学 2026 级新生规模分布 · 交互式旭日图

数据可视化课程作业：统计嘉兴大学 2026 级新生人数，用**旭日图**呈现「学院 → 专业」两层结构，
支持点击学院下钻、查看人数占比。

同一份数据做了**两个版本**，用途不同：

| 版本 | 位置 | 定位 |
|---|---|---|
| **A. 大屏增强版** | 仓库根目录 | 单页应用式布局：指标卡 + 图表 + 学院排行栏 + 导出 PNG，适合展示 |
| **B. pyecharts 纯代码版** | `复现/` | 只有一段 `Sunburst().add(...).render()`，白底无装饰，与老师给的参考图逐项对齐，适合交作业 |

两个 HTML 都是**单文件**（ECharts 5.5.1 已内联），**断网双击即可打开**，不依赖任何 CDN。

## 在线预览

GitHub 不渲染 HTML，所以：

- 想直接看效果 → 下载 `嘉兴大学新生人数旭日图.html`（或 `复现/嘉兴大学新生人数旭日图.html`）后双击；
- 想看截图 → 仓库里的 `预览_总览.png`、`预览_下钻.png`（两个版本各有两张）。

## 数据口径

- **总量 4,638 人**，15 个学院、61 个专业；脚本内置断言校验 `Σ专业 = Σ学院 = 4638`。
- 学院人数取自参考图可辨识的数值（商学院 549、医学院 534、人工智能学院 481、经济学院 413、
  数据科学学院 401、设计学院 383、文法学院 360、机械工程学院 308…），专业人数按「学院合计」约束拆分；
  设计学院四个专业 132 / 101 / 92 / 58 = 383，与参考图逐一对应。
- 学院与专业名称取自嘉兴大学教务处《本科专业设置一览表》，确保专业真实存在。
- 注意：学校招生办 2026 新生大数据推文的口径是 **6,010 人（含专升本 / 研究生）**，
  本作业用的是**普通本科 4,638**，两者不是一回事，不要混用。

## 运行

依赖 `pyecharts >= 2.0`（开发环境 anaconda 自带 2.1.0），B 版 notebook 另需 JupyterLab。

```bash
python sunburst_jiaxing.py          # A 版：重新生成 嘉兴大学新生人数旭日图.html
python 复现/sunburst_repro.py       # B 版：重新生成 复现/嘉兴大学新生人数旭日图.html
```

改数据只需要编辑 `data/新生人数.csv` 的「人数」列（新增专业就加一行，学院名保持一致），
然后重跑脚本 —— 脚本会打印各学院小计与占比核对表。

## 交互

| 操作 | 效果 |
|---|---|
| 悬停扇区 | 提示框显示：人数、占本层（父级）比例、占总体（全校 4638）比例 |
| 点击学院扇区 | 下钻：中心变为该学院名与人数，外圈只剩它的专业 |
| 点击面包屑 / 圆心 / 「返回总览」 | 回到全校视图（A 版三者都有；B 版为点击圆心） |
| 「导出 PNG」（仅 A 版） | 当前视图导出 2.5 倍分辨率 PNG |
| 地址加 `#学院名`（仅 A 版） | 直接定位，如 `嘉兴大学新生人数旭日图.html#设计学院` |

## 实现要点（踩坑记录）

两个版本共通的三个坑，写在代码注释里也记在这：

1. **`levels` 索引偏移**：ECharts 的 `levels[i]` 实际作用于第 `i-1` 层，`levels[0]` 是空占位，
   `levels[1]` 才对应根节点（中心），所以配置里能看到一个空对象打头。
2. **`JsCode` 里不能用 `//` 行注释**：pyecharts 序列化时会把函数体压成一行，`//` 会把后面代码全注释掉，
   表现为整个页面空白。必须用 `/* */`。
3. **`treePathInfo` 第 0 项是 series 自身**：真实层级要 `path.length - 1`，否则「学院 / 专业」判定全错。

另外两版下钻的实现不同，原因在 `复现/README.md` 里详述：A 版用「以学院为根重建 option」，
B 版为了保持纯 pyecharts 风格，用一段 `setTimeout` 包裹的 `setOption` 重建两层树 ——
因为 ECharts 自带的 `nodeClick="rootToNode"` 下钻后会把「全校」那层留在圆心，变成三层，和参考图不符。

## 已知取舍

- 专业环中占比过小（< 0.8%）的扇区不显示标签，避免文字互相压盖，数值仍可悬停查看；
- 图上学院 / 专业名为简称（如「材料与纺织」「数据科学(大)」），提示框里是教务处官方全称；
- B 版 11 点到 1 点方向的几个小规模学院标签仍偏挤，这是 pyecharts 默认径向布局的固有表现，
  参考图原图同一区域也一样拥挤。
