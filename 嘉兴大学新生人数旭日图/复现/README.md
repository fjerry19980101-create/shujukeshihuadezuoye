# 嘉兴大学 2026 级新生人数 · 旭日图（pyecharts 复现版）

与参考图同款：**纯 pyecharts 代码**、白底、两层「学院 → 专业」、中心显示总数、点击学院下钻。
没有大屏装饰、没有额外 CSS —— 整个页面就是 `Sunburst().add(...).render()` 的默认产出。

---

## 一、文件

| 文件 | 说明 |
|---|---|
| **旭日图_复现.html** | 成品，1 MB 单文件，ECharts 已内联，**断网双击即可打开** |
| **旭日图.ipynb** | JupyterLab 版（和参考图同一个环境），打开直接跑，图表内嵌显示 |
| **sunburst_repro.py** | 主脚本，Spyder / 命令行都能跑，跑完自动用浏览器打开 |
| **data/新生人数.csv** | 数据源（学院, 专业, 人数），可用 Excel 直接改 |
| 预览_总览.png / 预览_下钻.png | 两张效果截图 |

## 二、怎么跑

**方式 1（看效果，最省事）**：双击 `旭日图_复现.html`。

**方式 2（改数据重出图）**
```bash
python sunburst_repro.py
```
会重新生成 `旭日图_复现.html`，并在控制台打印每个学院的小计与占比。

**方式 3（和参考图一样在 JupyterLab 里）**
```
jupyter lab  →  打开 旭日图.ipynb  →  Run All
```

依赖：`pyecharts >= 2.0`（本机 2.1.0），Python 3.8+。

## 三、图上能做什么

| 操作 | 效果 |
|---|---|
| 悬停任意扇区 | tooltip 显示 `人数 / 占本层 / 占总体`，字段与参考图一致 |
| 点击学院 | 圆心变成该学院（名 + 人数），外圈只剩它的专业，整体变两圈 |
| 点击圆心 | 退回全校总览 |

「占本层」= 该扇区人数 ÷ 同层父节点人数，「占总体」= ÷ 4638，都是**未取整的原始比值**（参考图上就是 `0.34464751958224543` 这种），和老师给的样子完全一致。

## 四、数据口径

- 全校 **4638 人**，15 个学院、61 个专业；
- 各学院人数与参考图一致（商学院 549、医学院 534、人工智能 481、经济 413、数据科学 401、设计 383、文法 360…），专业人数按学院合计拆分；
- 设计学院四个专业 132 / 101 / 92 / 58 = 383，与参考图逐一对应；
- 学院人数由专业人数汇总得到，全校合计 4638；脚本每次运行都会打印核对表（每院小计 + 占比），一眼能看出对不上；
- 注意：招生办推文里的 **6010 人**是含专升本/研究生的全口径，这张图是**普通本科 4638**，两者不要混用。

## 五、和参考图的几处差别（有意为之）

1. **长专业名截断**：超过 110px 用「…」省略，避免文字顶出扇区；悬停 tooltip 里是完整名称。
2. **带括号的学院名只显示主名**（如「机械工程学院（机器人工程学院）」图上写「机械工程学院」），tooltip 里是官方全名。
3. **占比 < 0.4% 的小扇区不标文字**，否则小角度的文字会糊成一片；数值悬停可见。
4. **下钻方式**：ECharts 自带的 `nodeClick="rootToNode"` 会把「全校」那一层也留在圆心，下钻后变成三层、圆心还挂着个 4638，和参考图不符。所以改成点击后用该学院重画一棵两层树（`drill_js()`，约 30 行，写在 `sunburst_repro.py` 里），下钻效果与参考图一致。
5. **关闭动画**（`animation = False`）：下钻瞬间重绘，不留残影。
