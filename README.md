# 《Excel数据可视化——从图表到数据大屏》Python 复现

把书中用 Excel 原生图表、数据透视表、切片器、VBA 和 PPT 做出来的每一张图，逐张用 Python 重新画一遍。
目标不是"能跑出个大概"，而是**版式、配色、字号、标注位置都与原著对齐**——坐标大多是从参考截图上量出来的。

- **静态图表** → Matplotlib（按设计像素设画布，落盘 PNG）
- **动态交互图** → Plotly（输出可交互 HTML，再用 headless Chrome 截成 PNG / GIF）
- **数据看板** → Matplotlib 逐像素复现，或 Plotly 单页 HTML

## 嘉兴大学新生人数旭日图（课程作业）

统计嘉兴大学 2026 级新生人数（**4,638 人 / 15 个学院 / 61 个专业**），用旭日图呈现
「学院 → 专业」两层结构，点击学院可下钻查看专业构成，悬停显示人数与占比。

同一份数据两个版本，用途不同：

| 版本 | 文件 | 定位 |
|---|---|---|
| 大屏增强版 | `嘉兴大学新生人数旭日图.html` | 指标卡 + 图表 + 学院排行栏 + 导出 PNG，适合展示 |
| 纯代码复现版 | `复现/嘉兴大学新生人数旭日图.html`<br>`复现/嘉兴大学新生人数旭日图.ipynb` | 只有 `Sunburst().add(...).render()`，白底无装饰，与参考图逐项对齐 |

两个 HTML 都是**单文件、ECharts 5.5.1 已内联、断网双击可开**。GitHub 不渲染 HTML，
要在线看效果请下载后打开，或直接看仓库里的 `预览_总览.png` / `预览_下钻.png`。

```bash
python "嘉兴大学新生人数旭日图/sunburst_jiaxing.py"      # 大屏增强版
python "嘉兴大学新生人数旭日图/复现/sunburst_repro.py"    # 纯代码复现版
```

数据源为 `data/新生人数.csv`（学院, 专业, 人数），改完重跑脚本即可；
脚本会断言 `Σ专业 = Σ学院 = 4638`。注意招生办推文的 **6,010 人**是含专升本 / 研究生的全口径，
本作业用的是**普通本科 4,638**。细节见该目录下的两个 README。

## 需要注意的三件事

1. **数据路径是作者的绝对路径。** 所有脚本顶部都有类似
   `XLSX = r"C:\Users\fjwsm\Desktop\...\1 渐变柱形图.xlsx"` 的常量，
   克隆到别的机器上要先改成自己的路径（或改成相对 `os.path.dirname(__file__)`）。
2. **第二章的原始 xlsx 未随仓库提供。** 那 30 张图读的是书中配套工作簿，属于教材素材，
   这里只保留了代码与渲染结果；第三章、第四章用到的 xlsx 已一并提交。
3. **字体为「微软雅黑」。** 非 Windows 环境需要替换成等价字体，否则中文标签会缺字。
